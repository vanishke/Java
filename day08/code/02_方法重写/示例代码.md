# 02_方法重写

## PersonDemo.java

```java
/*
	方法重写注意事项：
		A:父类中私有方法不能被重写
		B:子类重写父类方法时，访问权限不能更低
			建议一样即可。
		C:父类静态方法，子类也必须通过静态方法进行重写。
*/
class Person {
	public void show() {
		System.out.println("show person");
	}	

	private void show2() {
		System.out.println("show2 person");
	}

	public void show3() {
		System.out.println("show3 person");
	}

	public static void show4() {
		System.out.println("show4 person");
	}
}

class Student extends Person {
	public void show() {
		System.out.println("show student");
	}

	private void show2() {
		System.out.println("show2 student");
	}

	public void show3() {
		System.out.println("show3 student");
	}

	public static void show4() {
		System.out.println("show4 student");
	}
}

class PersonDemo {
	public static void main(String[] args) {
		Student s = new Student();
		s.show();
		//s.show2();
		s.show3();
		s.show4();
	}
}
```

class Phone {
	public void call(String name) {
		System.out.println("给"+name+"打电话");
	}
}

class NewPhone extends Phone {
	public void call(String name) {
		System.out.println("听彩铃");
		//System.out.println("给"+name+"打电话");
		super.call(name);
	}
}

class PhoneDemo {
	public static void main(String[] args) {
		//手机
		Phone p = new Phone();
		p.call("林青霞");
		System.out.println("-----------");
