# 03_循环语句(do...while)

## DoWhileDemo.java

```java
/*
	do...while格式：
		do {
			语句体;
		}while(条件表达式);

	变形格式：
		初始化语句;
		do {
			循环体语句;
			控制条件语句;
		}while(判断条件语句);
		
		
		for(初始化语句;判断条件语句;控制条件语句) {
			 循环体语句;
		}
*/
class DoWhileDemo {
	public static void main(String[] args) {
		/*
		int sum = 0;
		for(int x=1; x<=100; x++) {
			sum+=x;
		}
		System.out.println(sum);
		*/

		//do...while
		int sum = 0;
		int x = 1;
		do{
			sum+=x;
			x++;
		}while (x<=100);
		System.out.println(sum);
	}
}
```

## DoWhileTest.java

```java
/*
	三种循环的区别：
		A:do…while循环至少会执行一次循环体。
		B:for循环和while循环只有在条件成立的时候才会去执行循环体。

	注意事项：
		A:写程序优先考虑for循环，再考虑while循环，最后考虑do…while循环。
		B:最简单的死循环代码
			for(;;){}
		
*/
class DoWhileTest {
	public static void main(String[] args) {
		/*
		for(int x = 10; x>20; x++) {
			System.out.println("hello");
		}

		int y = 10;
		while(y>20){
			System.out.println("world");
			y++;
		}

		int z = 10;
		do{
			System.out.println("java");
			z++;
		}while(z>20);
		*/
	
		/*
		for(;;){
			System.out.println("haha");
		}
		*/

		while(true) {
			System.out.println("haha");
		}
	}
}
```
