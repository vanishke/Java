# Java语言运算符优先级表

> 由 `day02/Java语言运算符优先级表.doc` 转换。

运算符的优先级（从高到低）

| 优先级 | 描述 | 运算符 |
| --- | --- | --- |
| 1 | 括号 | ()、[] |
| 2 | 正负号 | +、- |
| 3 | 自增自减，非 | ++、--、! |
| 4 | 乘除，取余 | *、/、% |
| 5 | 加减 | +、- |
| 6 | 移位运算 | <<、>>、>>> |
| 7 | 大小关系 | >、>=、<、<= |
| 8 | 相等关系 | ==、!= |
| 9 | 按位与 | & |
| 10 | 按位异或 | ^ |
| 11 | 按位或 | \| |
| 12 | 逻辑与 | && |
| 13 | 逻辑或 | \|\| |
| 14 | 条件运算 | ?: |
| 15 | 赋值运算 | =、+=、-=、*=、/=、%= |
| 16 | 位赋值运算 | &=、\|=、<<=、>>=、>>>= |

如果在程序中，要改变运算顺序，可以使用()。
